🐤 Canary Cloud scaffold

Paid API users can't verify they're getting the model they paid for. This is the hosted canary — your keys never leave your browser.

1. Your keys (BYO)

Stored only in this browser's localStorage. The Canary Cloud server has no endpoint that accepts keys — sending one gets a loud 400, by design.

2. Run canary probes

Probes run in your browser, straight at your provider. Only keyless results go to /api/verdict.

3. Proof panel

Every outbound fetch this page makes, logged live. Verify: keyed requests go to your hosts; our server only ever sees keyless JSON. Cross-check in DevTools → Network.
